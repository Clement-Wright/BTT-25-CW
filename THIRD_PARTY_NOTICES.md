# External components

This project's [LICENSE](LICENSE) covers its original implementation. External datasets, model weights, dictionaries and software retain their own terms. They are acquired separately; this repository does not bundle a dataset, pretrained model or third-party source tree.

- **Official T15 assets.** Obtain the features and checkpoint from the [Dryad deposit](https://datadryad.org/dataset/doi:10.5061/dryad.dncjsxm85). Dryad's [terms](https://datadryad.org/terms) describe CC0 dataset publication. Cite the deposit and [Card et al., NEJM 2024](https://doi.org/10.1056/NEJMoa2314132). Dataset terms are separate from the neural source's redistribution status.
- **Official neural-model method.** No root source license was located at the inspected [Neuroprosthetics-Lab revision](https://github.com/Neuroprosthetics-Lab/nejm-brain-to-text/tree/980a5b7e96392210edf976d76bdb5d15d2e0e62b). Those source files are not vendored. A license in a nested component is not a grant for the whole repository.
- **Flashlight Text 0.0.7.** The pinned [upstream LICENSE](https://github.com/flashlight/text/blob/bbe9e3c201f5c9c3f3c0d553f0ea73af5e0a5209/LICENSE) is **MIT**, copyright Facebook, Inc. and its affiliates. This corrects the earlier BSD-style description. Retain that copyright and permission notice when redistributing the dependency or a modified build. The v2 terminal-label repair is built in an external checkout.
- **KenLM 0.3.0.** The estimator and native LM dependency are predominantly **LGPL-2.1-or-later**, with named file-level exceptions. Consult the pinned [LICENSE](https://github.com/kpu/kenlm/blob/4cb443e60b7bf2c0ddf3c745378f76cb59e254e5/LICENSE) and [COPYING](https://github.com/kpu/kenlm/blob/4cb443e60b7bf2c0ddf3c745378f76cb59e254e5/COPYING), alongside the acquired [release](https://pypi.org/project/kenlm/0.3.0/). A trained n-gram and its text corpus are separate assets.
- **CMUdict.** Its [two-condition redistribution notice](https://github.com/cmusphinx/cmudict/blob/74790861f652b15e4ac49015a90074ad62a27690/LICENSE), copyright Carnegie Mellon University, requires the notice, conditions and disclaimer to accompany source or binary redistribution. The notice is retained with local acquired/converted dictionaries.
- **DistilGPT2.** The pinned [model card](https://huggingface.co/distilbert/distilgpt2/blob/2290a62682d06624634c1f46a6ad5be0f47f38aa/README.md) declares **Apache-2.0**. Its OpenWebText pretraining and GPT-2 distillation are distinct from permitted local task text. Weights remain external.
- **Qwen3 base models.** The pinned [1.7B](https://huggingface.co/Qwen/Qwen3-1.7B-Base/blob/ea980cb0a6c2ae4b936e82123acc929f1cec04c1/README.md) and [4B](https://huggingface.co/Qwen/Qwen3-4B-Base/blob/906bfd4b4dc7f14ee4320094d8b41684abff8539/README.md) cards declare **Apache-2.0**. These general pretrained weights are separately acquired and are not task-fine-tuned here.
- **ImagineVille four-gram.** Keith Vertanen's [December 2019 model release](https://imagineville.org/software/lm/dec19/) declares **CC BY 4.0**. The continuation acquired the Small model; the LightBeam paper uses Huge. Preserve the release attribution with those assets.
- **BrainAudio/LightBeam source.** No root redistribution license was verified in the inspected [source revision](https://github.com/ebrahimfeghhi/brainaudio/tree/90e0ac086d4dee643be154f446a6c374600575d7). Its checkout and local runtime patch stay outside Git. The published system's Llama weights have [separate model terms](https://huggingface.co/meta-llama/Llama-3.2-1B); the local feasibility run used Qwen instead.
- **Other installed dependencies.** PyTorch, NumPy, SciPy, h5py, psutil, PyYAML, Transformers and plotting libraries are governed by their own published licenses.

[PROVENANCE.md](docs/PROVENANCE.md) records source revisions and acquisition history. The project's license does not replace any of these external notices.
