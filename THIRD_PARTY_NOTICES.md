# External components

No dataset, neural checkpoint, pretrained LM or third-party source tree is redistributed here. Original implementation code is licensed by this project's LICENSE; external assets retain their own terms.

- Official T15 data/checkpoint: [Dryad](https://datadryad.org/dataset/doi:10.5061/dryad.dncjsxm85). Read the source terms and cite Card et al. before use.
- Official model method/contracts: [Neuroprosthetics-Lab source revision](https://github.com/Neuroprosthetics-Lab/nejm-brain-to-text/tree/980a5b7e96392210edf976d76bdb5d15d2e0e62b). No root source license was located; source is not vendored.
- [Flashlight Text](https://github.com/flashlight/text): external CTC decoder dependency; BSD-style project terms apply to that package.
- [KenLM 0.3.0](https://pypi.org/project/kenlm/0.3.0/): external estimator and native language-model dependency. Consult the project's [LGPL notice](https://github.com/kpu/kenlm/blob/master/COPYING).
- [CMUdict license](https://github.com/cmusphinx/cmudict/blob/74790861f652b15e4ac49015a90074ad62a27690/LICENSE): preserve the dictionary notice with acquired/converted assets. Converted dictionary files remain local.
- [DistilGPT2](https://huggingface.co/distilbert/distilgpt2): Apache-2.0 model, used through Transformers. General OpenWebText pretraining is disclosed separately from permitted local task text.
- PyTorch, NumPy, SciPy, h5py, psutil, PyYAML, Transformers and plotting libraries are separately installed dependencies governed by their published licenses.
