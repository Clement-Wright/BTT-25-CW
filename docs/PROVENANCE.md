# Provenance

BTT-25-CW began with an audit of an unfinished T15 pipeline and a separate recovery of the official baseline. It has a fresh repository history. The original team/private repositories, local branches, checkpoints and uncommitted work were preserved.

The recovered model comes from the July 2025 [Dryad T15 release](https://datadryad.org/dataset/doi:10.5061/dryad.dncjsxm85), version 374060. Existing expanded neural data were reused after checking counts and contracts; per-file hashes remain in the private inventory. The model weights were acquired separately. During recovery, Dryad's public ZIP stream returned 403 in this environment. A [pinned independent Hugging Face mirror](https://huggingface.co/datasets/yw784/brain-to-text-25-competition/tree/2f2fabacbc9af637da3bac483bf14e1231fb4e8a) supplied an archive whose complete SHA-256 matched authoritative Dryad metadata. This establishes file identity without attributing the mirror to the dataset authors. The [asset manifest](../assets/manifest.json) records the archive, checkpoint and argument hashes separately.

Source and adapted author weights are not redistributed here. |

The original source audit found no root redistribution license for the official neural-model source or the inspected legacy candidates. A nested component's license does not cover its neighboring files. The same limitation applies to the inspected BrainAudio tree, whose checkout and runtime modifications remain external. By contrast, the pinned [Flashlight LICENSE is MIT](https://github.com/flashlight/text/blob/bbe9e3c201f5c9c3f3c0d553f0ea73af5e0a5209/LICENSE). Data, model weights, dictionaries and installed libraries keep their own terms; [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md) identifies the relevant notices.

The historical work inspected was Clement-Wright/BTT_private_work, Purdue-IEEE-SMC/Brain-to-Text-2025 and Clement-Wright/speechBCI_2024. The Purdue repository was available as a local clone even though the connected remote API returned 404. Its current branch differed from the private default examined in the handoff. Narendra Glasgow, CleWri00, Daniel Ng and corntoasted appear in its contributor history. The 2024-derived source credits TeamCyber/CIBR and the Stanford organizers. These credits describe the recovered work; they do not attribute the new implementation to those contributors. Incompatible checkpoint architectures and missing split/preprocessing provenance prevented reuse as a strict official baseline.

The released features already carry preceding-trial normalization. Recovery adds the checkpoint's required valid Gaussian smoothing, with no raw-signal high-gamma transform or per-utterance renormalization.

The [continuation runbook](CONTINUATION.md) links the immutable v1 archive and v2 registrations. Each experiment's private artifact bundle retains acquired-file hashes, model metadata, source revisions, configurations and attempt history. Public [v1](../reports/results.md) and [v2](../reports/continuation.md) reports contain measured aggregates; the [recovery audit](RECOVERY_AUDIT.md) records why the baseline was rebuilt.
