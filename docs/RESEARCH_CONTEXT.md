# Research context

Sources checked through 16 November 2026. Published measurements below retain their original participant, split and decoder conditions. Local measurements and unfinished work appear in [STATE.md](STATE.md); they do not inherit a paper's accuracy.

BTT-25-CW targets the T15 release associated with [Card et al., NEJM 2024](https://doi.org/10.1056/NEJMoa2314132). The [July 2025 Dryad deposit](https://datadryad.org/dataset/doi:10.5061/dryad.dncjsxm85) provides processed neural features and a separate pretrained GRU. This is attempted speech recorded through intracortical electrodes. T12/Brain-to-Text '24, T15/Brain-to-Text '25 and later clinical use involve different data and evaluation conditions.

The [official PyTorch recipe](https://github.com/Neuroprosthetics-Lab/nejm-brain-to-text/blob/980a5b7e96392210edf976d76bdb5d15d2e0e62b/model_training/README.md) supplies the recovery anchor: day-specific transforms, five 768-unit GRU layers and phoneme CTC. Its approximately 10.1% validation PER and 3.5-hour RTX 4090 training time describe the authors' recipe. They are neither local acceptance thresholds nor a laptop runtime forecast. Its trainer uses same-padded smoothing while the supplied inference helper uses valid smoothing; a numerical comparison must identify the path.

| Published direction | Evidence and relevance here |
|---|---|
| Context-dependent diphones | [Li et al., DCoND v1, November 2024](https://arxiv.org/html/2411.10657v1) marginalize diphone probabilities into ordinary phoneme probabilities. On T12 they report 15.34% PER versus 16.62% for monophones; 5.77% WER belongs to the larger system with adapted LMs. Recovering an auxiliary diphone head would be a new adaptation of this idea. It would require its own vocabulary, blank, target-construction and marginalization tests, and would not reproduce that complete system. |
| Time masking and online adaptation | [Feghhi et al., v2, November 2025](https://arxiv.org/html/2507.02800v2) study causal transformers and DietCORP: language-derived pseudo-labels, augmented copies of the current trial and an input-module update. Their held-out-day protocol differs from supervised updates within known T15 sessions. Author code was inspected, but a ready neural checkpoint was not verified. |
| Large-scale neural pretraining | [Zhang et al., BIT v5, May 2026](https://arxiv.org/html/2511.21740v5) study cross-species pretraining and cascaded/end-to-end decoding. Appendix R reports encoder pretraining on an A100 80 GB in under two days, followed by task training. The [inspected MIT-licensed code release](https://github.com/yzhang511/bit/tree/f107ae988d782609b78d1d7488490cca9fb7a103) did not establish a ready pretrained-weight download. This is a separate reproduction effort. |

Clinical progress also changes the research questions. [Card et al., Nature Medicine 2026](https://pmc.ncbi.nlm.nih.gov/articles/PMC13375540/) report prolonged independent use with a transformer and continued adaptation; their personal-use neural data and transcripts are not shared. [Fogg et al., July 2026 preprint](https://pmc.ncbi.nlm.nih.gov/articles/PMC13483768/) describe shared training across six participants and rapid held-out-user calibration. These motivate transfer research, but neither establishes a turnkey replacement for this public T15 checkpoint or a result on this project's split.

[LightBeam v1, March 2026](https://arxiv.org/html/2603.14002v1) is the closest published decoder alternative: it combines lexicon constraints, a 4-gram and periodic Llama scoring during search. Table 1 reports 5.77% public and 6.47% private T15 WER with the baseline GRU, using 11.6 GB host RAM and 5.8 GB VRAM; timing uses an RTX 5090. This repository has not reproduced those results. Integration remains deferred for the following concrete reasons.

| Dependency or constraint | Audited status |
|---|---|
| Large external n-gram | The [pinned BrainAudio README](https://github.com/ebrahimfeghhi/brainaudio/blob/90e0ac086d4dee643be154f446a6c374600575d7/README.md) requires the unbundled Huge 4-gram. [ImagineVille](https://imagineville.org/software/lm/dec19/) lists a 4.9 GB compressed download under CC BY 4.0. Download size is not peak loaded memory. |
| Whole-pipeline memory | The published peaks fit within the nominal memory of the A100 and the available Gilbreth host allocation. A port would still need to measure n-gram loading, search, Llama caches and the encoder together. The published 11.6 GB host peak leaves less headroom under the laptop's 12 GB target. |
| Code and trained assets | No root redistribution license or ready author neural-checkpoint link was verified in the inspected BrainAudio tree. A matching fine-tuned Llama adapter was not verified either. [Llama 3.2](https://huggingface.co/meta-llama/Llama-3.2-1B) has its own license/access terms. Public source availability does not supply these weights or permissions. Official cached logits could support a later decoder-only integration. |
| Text exposure | LightBeam section 3.4.2 says next-word tuning uses train plus validation text; Appendix F instead describes training text and validation tuning. Appendix G explicitly uses validation text for generative correction. This ambiguity prevents treating an imported task-adapted LM as independent of local validation. |

The current studies ask smaller questions. Confidence gating compares additional scoring of fixed word candidates against scoring all trials and a matched random control. The revision-pinned [DistilGPT2 card](https://huggingface.co/distilbert/distilgpt2/blob/2290a62682d06624634c1f46a6ad5be0f47f38aa/README.md) identifies Apache 2.0 terms, OpenWebText and GPT-2 distillation. Its likelihood scorer preserves candidate text and generates nothing; unknown overlap with benchmark sentences remains a limitation. The baseline's native lexicon-only fallback has lower language capacity than a trained 3-gram and must be named accordingly.

Session calibration compares the unchanged checkpoint, its output head, and that same head plus existing session biases. Labels come from official training trials in sessions already seen by the source model. This tests further calibration within known sessions; it does not establish unseen-day transfer or reproduce DietCORP. Diphone work remains deferred.

The optional paired-electrode ablation needs a verified electrode-to-column map. The published release describes modality and array blocks, but its first range includes 0–64 and later ranges end at 512 for a 512-column tensor. The inspected HDF5 feature dataset carried no column identifiers. We deferred paired masks pending an unambiguous mapping. [Pinned organizer feature description](https://github.com/Neuroprosthetics-Lab/nejm-brain-to-text/blob/980a5b7e96392210edf976d76bdb5d15d2e0e62b/README.md#data)

New choices use `dev_tune`; both primary studies must freeze before reporting references are opened. The inherited checkpoint was selected using official validation, so the local reporting partition protects new choices only. Corpus WER/PER, failures, paired uncertainty and measured total resource cost govern the comparison.
