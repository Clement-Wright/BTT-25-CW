# Four cued inner-speech commands on scalp EEG

This comparison uses participant 01 in the CC0 OpenNeuro Inner Speech dataset, version 2.0.0. Fit on sessions 01 and 02. Score session 03 once. Each trial has one of four Spanish directions. The outcome is command accuracy. [Dataset and license](https://github.com/OpenNeuroDatasets/ds003626/blob/2.0.0/dataset_description.json) · [Task protocol and event codes](https://pmc.ncbi.nlm.nih.gov/articles/PMC8844234/)

Use the raw 1,024 Hz BioSemi BDF, all 128 scalp channels, and the mean of the two earlobe reference channels. Take trials only from runs marked 22. The class cue takes codes 31 through 34 (arriba, abajo, derecha, izquierda). Extract two seconds starting 250 ms after action onset, code 44. Reject ambiguous event sequences with an error. Use no visual cue samples, external muscle channels as predictors, or session-wide artifact removal. A cue can still leave a visual or eye-movement response after it disappears.

For each channel, calculate log mean Welch power in 4–8, 8–13, 13–20 and 20–40 Hz with half-second Hann windows and 50% overlap. Fit each feature's mean and standard deviation on the training sessions. Fit one-vs-rest ridge least squares to centered one-hot class indicators with a fixed penalty equal to the training sample count. Use the largest score. Repeat the identical fit using a two-second window ending 125 ms before the class cue; this includes the preceding rest interval. Report both accuracies against the 25% uniform chance rate, counts per class, a confusion matrix, Wilson intervals and inference timing. No trials are removed based on score, muscle activity or test features.

The fixed training rule has no validation sweep. Keep the subject, tasks, windows, channels, regularization and held-out session fixed. Save per-trial predictions on scratch and publish aggregate results. The test uses known trial boundaries from a 128-channel research recorder. A consumer EEG cap and self-paced word detection require separate measurements.
